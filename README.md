# yolo_onnx_ros

C++ YOLO object detection using a single executable with two selectable backends:

| Backend | Flag | Speed | Requirement |
|---|---|---|---|
| ONNX Runtime + CUDA | `--backend=onnx` (default) | ~25 ms/frame | ONNX Runtime GPU build |
| TensorRT FP16 | `--backend=tensorrt` | ~6 ms/frame | CUDA + TensorRT |

Both backends support any Ultralytics YOLO model (YOLO11, YOLO26, etc.) and automatically detect the output format — including the YOLO26 NMS-free head.

## Project Structure

```
yolo_onnx_ros/
├── CMakeLists.txt
├── images/                          # Test images
├── models/                          # Place model files here
│   ├── yolo26m.onnx
│   ├── yolo26m.trt                  # Generated by trtexec (see below)
│   ├── coco.yaml                    # Class names (ONNX backend)
│   └── coco.names                   # Class names (TRT backend, one per line)
├── include/
│   ├── yolo_onnx_ros/               # ONNX backend headers
│   │   ├── config.hpp.in
│   │   ├── detection.hpp
│   │   └── yolo_inference.hpp
│   └── yolos/                       # TensorRT backend (header-only)
│       ├── core/                    # Engine, CUDA preprocessing, NMS
│       └── tasks/detection.hpp      # TRT detection API
└── src/
    ├── detection.cpp                # ONNX backend implementation
    ├── yolo_inference.cpp           # ONNX session + output parsing
    └── main.cpp                     # Unified entry point (both backends)
```

## Dependencies

### Always required
| Dependency | Version | Install |
|---|---|---|
| CMake | ≥ 3.5 | `sudo apt install cmake` |
| OpenCV | ≥ 4.5 | `sudo apt install libopencv-dev` |
| console_bridge | any | `sudo apt install libconsole-bridge-dev` |
| ONNX Runtime (GPU) | 1.20.1 | See below |

### Required only when `CUDA_ENABLED=ON`
| Dependency | Version | Install |
|---|---|---|
| CUDA Toolkit | ≥ 12.0 | `sudo apt install nvidia-cuda-toolkit` |
| cuDNN | 9 | `sudo apt install libcudnn9-cuda-12 libcudnn9-dev-cuda-12` |
| TensorRT | ≥ 10.0 | `sudo apt install libnvinfer-dev libnvinfer-bin` |
| NVIDIA GPU | CC ≥ 7.5 | Driver managed by Windows (WSL2) |

### Install ONNX Runtime (GPU build)
```bash
wget https://github.com/microsoft/onnxruntime/releases/download/v1.20.1/onnxruntime-linux-x64-gpu-1.20.1.tgz
tar -xzf onnxruntime-linux-x64-gpu-1.20.1.tgz
sudo cp -r onnxruntime-linux-x64-gpu-1.20.1/include /usr/local/onnxruntime/
sudo cp -r onnxruntime-linux-x64-gpu-1.20.1/lib     /usr/local/onnxruntime/
echo '/usr/local/onnxruntime/lib' | sudo tee /etc/ld.so.conf.d/onnxruntime.conf
sudo ldconfig
```

> **WSL2 note:** CUDA device detection requires the WSL2 CUDA stub:
> ```bash
> export LD_LIBRARY_PATH=/usr/lib/wsl/lib:$LD_LIBRARY_PATH
> ```

## Build

### ONNX backend only
```bash
cmake -DCMAKE_BUILD_TYPE=Release \
      -DONNXRUNTIME_ROOT=/usr/local/onnxruntime \
      -S . -B build
cmake --build build
```

### ONNX + TensorRT backends
```bash
cmake -DCMAKE_BUILD_TYPE=Release \
      -DONNXRUNTIME_ROOT=/usr/local/onnxruntime \
      -DCUDA_ENABLED=ON \
      -S . -B build
cmake --build build
```

If TensorRT is installed to a non-standard path, add `-DTENSORRT_ROOT=/path/to/tensorrt`.

## Models

### Export ONNX from a pretrained checkpoint
```bash
pip install ultralytics
python -c "from ultralytics import YOLO; YOLO('yolo26m.pt').export(format='onnx')"
```

Copy the resulting `yolo26m.onnx` and the matching `coco.yaml` into `models/`.

### Generate a TensorRT engine
```bash
trtexec \
  --onnx=models/yolo26m.onnx \
  --saveEngine=models/yolo26m.trt \
  --fp16
```

### Generate `coco.names` (for TRT backend)
```bash
grep -A 1000 "^names:" models/coco.yaml \
  | tail -n +2 | grep -E "^\s+-" \
  | sed 's/.*- //' \
  > models/coco.names
```

## Run

The executable is at `build/test_yolo_onnx_ros`.

### ONNX Runtime backend (default)
```bash
cd build
LD_LIBRARY_PATH=/usr/lib/wsl/lib:$LD_LIBRARY_PATH \
./test_yolo_onnx_ros ../models/yolo26m.onnx ../images --backend=onnx
```

### TensorRT backend
```bash
cd build
LD_LIBRARY_PATH=/usr/lib/wsl/lib:$LD_LIBRARY_PATH \
./test_yolo_onnx_ros ../models/yolo26m.trt ../images \
  --backend=tensorrt \
  --labels=../models/coco.names
```

`--labels` is optional — omitting it runs inference without class name labels.

### Full usage
```
Usage: ./test_yolo_onnx_ros <model> <images_dir> [--backend=onnx|tensorrt] [--labels=<file>]
  --backend=onnx       ONNX Runtime + CUDA  (default)
  --backend=tensorrt   TensorRT engine (.trt)
  --labels=<file>      Class names file (one per line; used by tensorrt backend)
```
